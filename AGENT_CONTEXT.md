# Agent Context

This repository is a static, single-page Astro portfolio for Logan Ponik.

## Architecture

- `src/pages/index.astro` is the only route and contains the complete visible page structure.
- `src/data/site.ts` is the single source for portfolio content and external links.
- `src/layouts/BaseLayout.astro` owns the HTML document, fonts, and SEO metadata.
- `src/styles/global.css` owns the visual system and responsive behavior.
- The production page uses semantic Astro/HTML only. There are no client directives, framework islands, animations, forms, APIs, or runtime state.

## Content and assets

The page order is Header, Hero, About, Experience, Skills, Projects, and Contact. The project list contains Rocky Linux Homelab, Terraform AWS Infrastructure, and Terris.

Referenced assets:

- `public/assets/lponik-headshot.jpg` for social metadata
- `public/assets/Lponik_Resume_2026.docx (10).pdf` for the resume link

The encoded resume URL in `site.ts` is intentional because the filename contains a space.

## Deployment

- Production: `https://www.loganponik.com/`
- Hosting: GitHub Pages
- Workflow: `.github/workflows/deploy.yml`
- Sitemap: generated by `@astrojs/sitemap`
- Package manager: npm

## Working rules

1. Preserve the static-first architecture unless a requested feature truly needs browser JavaScript.
2. Make content edits in `src/data/site.ts`.
3. Keep the domain aligned across `astro.config.mjs`, `CNAME`, and `public/robots.txt`.
4. Preserve semantic markup, accessible labels, visible focus styles, and reduced-motion handling.
5. Run `npm run build` before handoff. No formatter, linter, or test script is currently configured.
